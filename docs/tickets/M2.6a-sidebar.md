## What the user saw (iPhone, dark mode)

The sidebar is cluttered: every workspace row has a chevron and expands into its agents, so the
list repeats each name twice ("M2.5b polish" → "M2.5b polish (DeepSeek)"). Projects ("Paseo-client",
"fixture-terminals") are plain non-collapsible headers. Settings sits at the top. The bottom shows
an avatar plus a server id and a "…" button.

## Target structure (Paseo's model)

Agents are **not** listed in the sidebar. They are the tabs inside a workspace (the chat header's
tab chips already do this). The sidebar lists projects → workspaces only.

1. **Top**: serif "Paseo" title, then nav rows in ClaudeUI's row style: **Scheduled** (opens the
   existing placeholder sheet). Nothing else for now; no Settings row up here.
2. **Projects are the collapsible level.** Project row: project name in the secondary section
   style it has now, a disclosure chevron that rotates, and a trailing `+` button that creates a
   new **agent in that project's most recently active workspace** (reuse the existing New agent
   flow / `ClaudeNewAgentSheet`, preselecting that workspace). Tapping the row toggles collapse
   with the existing height roll; collapsed state persisted (`@AppStorage`, keyed by project id).
   Selection haptic on toggle.
3. **Workspace rows** (no chevron, not expandable): one line title (workspace title, or branch
   if none), a secondary meta line `branch · relative last activity` ("main · 5m"), a leading
   status dot aggregated from its agents (needs input / failed / working / done / unread, same
   colors as today), and an unread/attention indicator. Tap opens the workspace: its most recent
   agent's conversation, with the other agents as header tabs (existing behavior). Selected row
   gets the current selected plate.
4. **Sorting**: workspaces within a project by last activity (newest first: max of the workspace's
   agents' last activity/updated time, falling back to the workspace's own timestamp). Projects
   ordered by their newest workspace. Use whatever timestamps the descriptors/agents actually
   expose; say which in your final message.
5. **Long press** (context menu) on a workspace: New agent here, Rename workspace, Copy path,
   Copy branch name, Archive workspace (with confirmation). On a project: New agent, Copy path,
   Remove project (with confirmation, only if `supportsProjectRemove`). Only actions the stores
   support; list missing ones.
6. **Bottom bar, like Claude iOS**: left, a round avatar button (glass circle, first letter of
   the user's name, or "P"), which opens Settings. Right of it, a white capsule button
   "New workspace" with a `plus` icon (ClaudeUI's old "New session" pill: black text on white,
   inverted in light mode). It opens a minimal new-workspace sheet in ClaudeUI sheet chrome: pick
   project (default: the selected workspace's project), optional name, create through
   `WorkspaceDirectory.createWorkspace` (look at its parameters; worktree off the project's
   current branch is the default). Gate on `supportsWorkspaceCreate`. Remove the server id and
   "…" from the bottom.
7. **Settings sheet**: move "Disconnect" (and the host/server id display) into the existing
   Settings sheet as a section at its bottom ("Host": server id, connection state dot,
   Disconnect in destructive style with confirmation).
8. **Agent controls sheet** (`Chat/ClaudeAgentControlsSheet.swift`): the Model / Thinking / Mode
   rows show SF Symbol icons. Remove the icons; plain row titles in the sheet's normal row font.
