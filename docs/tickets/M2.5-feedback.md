## M2.5a: bugs (branch `m25a-bugs`)

Each bug: find the root cause using the live daemon (`swift run paseo-probe ...`, the fixture
sandbox agent `1c51ee58-765c-4f8d-bf27-7009338b361e` in `/tmp/fixture-sandbox`, or agents you
create there and archive afterwards), fix it in the right layer, add a regression test in
PaseoCore where the cause is in the store/kit layer. Never touch the user's real agents.

1. **Model switching does nothing.** In a chat, picking another model in the model sheet can be
   tapped repeatedly but the agent's model never changes. Same check for thinking/effort and mode.
   Verify against the daemon that the agent's model actually changes, and that the UI reflects it
   (the composer's model label comes from the agent's state as the daemon reports it).
2. **Providers missing.** Only Claude and opencode show; pi and omp are missing although the
   daemon has them (`paseo provider ls`, `paseo provider models pi`). Providers must come from
   the daemon automatically. Likely causes to check: entries still in a loading/probing state that
   are filtered out and never updated (`providers_snapshot_update` events?), slow model listing
   hitting a client timeout, or decoding of unknown fields. The pickers show every provider the
   daemon offers. A provider that is still loading shows as loading and fills in once ready.
3. **A timeout message keeps appearing on the composer.** Find which request times out (log every
   request type sent and its latency in a probe run that mimics what the chat screen does on open),
   fix the cause (wrong response matching, a request the daemon doesn't answer, a too-short
   timeout for a slow call). A timeout of a background request (heartbeat, catalogue refresh) must
   never surface on the composer; only failures of the user's own send/cancel do.

Touch PaseoCore as needed, plus `Chat/ClaudeAgentControlsSheet.swift`, `Chat/ClaudeNewAgentSheet.swift`
and the composer's error display in `Chat/ClaudeChatView.swift` (only the composer section). Do
not restyle anything.
